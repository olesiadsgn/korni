# Корни семьи

Семейная книга Кузьменко, Ваккер, Петровых (Мамот) и Ивановых: https://olesiadsgn.github.io/korni/

Книгу начал собирать Алексей Дмитриевич Кузьменко. Олеся продолжает его дело.

## Где что лежит
| Файл | Что внутри |
|---|---|
| `index.html` | Каркас страницы: обложка, меню, окна |
| `css/book.css` | Оформление: тёмно-серая оболочка, сливочные листы, шрифты Alegreya и Roboto |
| `js/data.js` | Люди (`P`): имена, даты, биографии, хронология, вопросы, источники. Места (`PL`) и связи людей с местами (`PMAP`) |
| `js/tree.js` | Схема древа: где кто стоит (`POS`), кто чей ребёнок (`FAM`), пары (`COUPLES`), пол (`G`) |
| `js/media.js` | Фото людей, подписи, галереи, видео, семейный архив |
| `js/app.js` | Логика: родство «кто тебе кто», главы, карточки, карта, хроника, древо |
| `data/world.json` | Контуры стран для глобуса. Грузится, только когда открывают «Места» |
| `photos/`, `video/` | Фото и видео |
| `brand/` | Брендбук книги |
| `podpisi/` | Страница для бабушки: подписать старые фото |
| `tools/build-bot-data.js` | Собирает людей, вопросы и дни рождения для семейного бота |

Сборки нет: файлы открываются браузером как есть. Чтобы посмотреть локально, запусти в папке `python3 -m http.server` и открой http://localhost:8000.

## Правила текстов
Короткие человеческие предложения, без длинных тире и пафоса, только то, что рассказали родные или что есть в документах. Личные документы используются только чтобы сверить даты, в книгу их не выкладываем.
